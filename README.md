# Primeiro_JSON

Exercício em **Node.js** para manipular uma lista de animes armazenada em JSON.

## Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `animes.json` | Base de dados com animes (título, autor, ano, episódios, sinopse, preço) |
| `animes.js` | Script que lê o JSON, adiciona itens, filtra por preço e aplica desconto |

## Funcionalidades

- Listar estoque de animes
- Adicionar novo anime
- Filtrar por preço máximo
- Aplicar 10% de desconto com `map`

## Como executar

```bash
node animes.js
```
